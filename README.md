## Set your `venv`

```sh
sudo apt update
sudo apt install python3-venv
```

## Installing required libraries

The following libraries are required to run the project on an Ubuntu server. Tk.nc@2024

```sh
sudo apt-get update
sudo apt install poppler-utils
sudo apt install tesseract-ocr tesseract-ocr-por
```
